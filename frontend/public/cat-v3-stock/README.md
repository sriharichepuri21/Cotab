# Tabby v3 production stock

This package contains 18 independently generated, square, transparent PNG
expressions based on the supplied approved Tabby master. No expression was
cropped from a multi-pose sheet.

## Identity lock

- Sage plush pear-shaped body and fixed head-to-height proportion
- Upright triangular ears with ivory interiors
- Fixed amber eye construction, spacing, irises and highlights
- Ivory face mask with central sage forehead point
- Dusty-rose triangular nose, W mouth and three whiskers per cheek
- Oval ivory belly and thick curled sage/ivory banded tail
- Viewer-facing palms/soles: four dusty-pink toe pads and one central pad
- Consistent front three-quarter camera and upper-left studio lighting

## Expressions

`hi`, `cool`, `hmm`, `over-budget`, `payday`, `need-money`, `out-of-cash`,
`bill-shock`, `love`, `salute`, `working`, `done`, `oops`, `remember`,
`autopilot`, `morning`, `celebrate`, and `thinking`.

`canonical-neutral.png` is the identity anchor. `reference-master.png` is the
user-approved source reference. The app has intentionally not been switched to
this stock yet; approval of the source library comes first.
